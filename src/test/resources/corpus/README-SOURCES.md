# Corpus sources

- `small.md`, `styles/*.md`, `security/*.md`: written for this project.
- `medium.md`, `large.md`: generated by `web/scripts/gen-corpus.mjs` (deterministic).
  `huge.md` (20 MB) is generated by the same script and is not in git.
- `readmes/*.md`: unmodified copies of README files from npm packages, MIT license. Each license text is next to it (`readmes/<name>.LICENSE`).
